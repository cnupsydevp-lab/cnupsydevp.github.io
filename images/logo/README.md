로고 이미지 폴더.

- 이곳에 올린 이미지는 `images/logo/<파일명>` 경로로 참조한다.
- 파일명은 용도를 앞에 두고 소문자로 쓴다:
  - `logo-full.png` — 심볼 + 글자 (가로형, 기본). 고해상도 원본 자리.
  - `logo-nav-body.png` / `logo-nav-balloon.png` — 내비 왼쪽 상단용 축소판을
    두 겹으로 나눈 것 (각 238×160). 풍선만 은은하게 흔들리게 하려고 가른다.
    페이지마다 불려 나가는 파일이라 원본(700KB대)을 그대로 쓰지 않는다.
    만드는 법: `logo-full.png` 을 표시 높이의 4배로 **먼저 줄이고**, 그 다음
    풍선 아래·글자 위(원본 y≈239, 높이의 30%)에서 가른다. 순서를 지켜야
    두 겹을 합쳤을 때 픽셀이 원본과 같아 정지 상태에서 이음선이 안 생긴다.
    원본을 바꾸면 두 파일을 같이 다시 만들고, 가르는 높이도 다시 재야 한다.
  - `logo-fullname.webp` / `logo-fullname.png` — 연구실 풀 이름
    (Noh Mental health And Digital care)이 풍선 글자로 그려진 로고.
    **홈 첫 화면 전체를 이것 하나로 채운다** (`index.html` → `.hero-wordmark`,
    제목·소개문·버튼 없음). 둘은 같은 그림이고 WebP 를 먼저 걸어(`<picture>`)
    옛 브라우저만 PNG 를 받는다 — WebP 252KB, PNG 933KB.
    `logo-fullname-source.png`(1536×1024, 투명 배경)에서 알파가 있는 범위만
    잘라낸 것 (x 23~1524, y 135~846 → 1502×712, 2.110:1). 늘리지 않았다.
    본문 폭 1016px 에 걸어 쓰므로 1.48배. 2배로 또렷하게 하려면
    2032px 이상으로 다시 렌더링해야 한다.
    ⚠️ **배경이 투명하므로 JPEG 로 바꾸지 말 것** — JPEG 는 알파를 담지 못해
    투명한 자리가 검정으로 구워지고, 종이 위에 검은 띠가 뜬다(한 번 겪었다).
    같은 이유로 틀·대지·그림자를 두르지 않는다. 투명한 자리에 사각형이 드러난다.
    ⚠️ 줄일 때는 **알파를 곱해 두고(premultiply) 줄인 뒤 다시 나눈다.**
    그냥 줄이면 투명한 곳의 검정(0,0,0)이 번져 글자 가장자리에 검은 테가 생긴다.
    ⚠️ 낱글자 단위 애니메이션은 이 파일로 할 수 없다 — 한 단어가 풍선 하나로
    이어 붙어 있다(예: 'And' 안에 글자색이 끊기는 열이 0개). 글자별로 튕기게 하려면
    글자마다 배경이 투명한 파일이 따로 있어야 한다.
  - `logo-mark.png` — 심볼만 (파비콘·프로필 사진용)
  - `logo-light.png` — 어두운 면(푸터·모달) 위에 얹는 밝은 버전
  - 같은 로고의 옛 버전을 남겨 둘 때만 뒤에 `_YYMMDD` 를 붙인다.
- 배경이 투명한 PNG(또는 SVG)로 올린다. 흰 사각형이 배경으로 박혀 있으면
  어두운 면 위에 얹을 수 없어 쓸 곳이 절반으로 줄어든다.
- 가로 폭은 최소 1200px 권장. 줄이는 건 되지만 늘리면 뭉개진다.
- 공유 미리보기 이미지(`images/og-image.png`, 1200×630)는 이 로고로 만든다.
  로고를 새로 올리면 og-image 도 같이 갱신해야 한다.
- 이 파일은 빈 폴더를 git 에 유지하기 위한 것으로, 이미지가 들어오면 삭제해도 된다.
