로고 이미지 폴더.

- 이곳에 올린 이미지는 `images/logo/<파일명>` 경로로 참조한다.
- 파일명은 용도를 앞에 두고 소문자로 쓴다:
  - `logo-full.png` — 심볼 + 글자 (가로형, 기본). 고해상도 원본 자리.
    2026-09-12 재업로드본은 "LIFE:ON" 글자에 하트·풍선 장식 (2042×685, 2.981:1,
    알파 있는 범위만 잘라냄). "LAB" 이 없는 짧은 마크다 — 전체 이름은
    `logo-fullname.png` 쪽에 있다.
  - `logo-nav-body.png` / `logo-nav-balloon.png` — 내비 왼쪽 상단용 축소판을
    두 겹으로 나눈 것 (같은 캔버스, 지금은 477×160). 원래 풍선만 은은하게
    흔들리게 하려고 가른 것인데, 2026-09-11 로고에는 흔들 요소가 따로 없어
    `logo-nav-body.png` 가 그림 전체를, `logo-nav-balloon.png` 는 완전히 빈
    캔버스를 담는다 — 두 겹 구조와 픽셀 맞춤 관례만 남겨 뒀다.
    페이지마다 불려 나가는 파일이라 원본(900KB대)을 그대로 쓰지 않는다.
    만드는 법: `logo-full.png` 을 캔버스 높이 160px 로 줄인다(표시 높이 44px 의
    3.6배 — 레티나 2배 요구를 넘는다). 원본을 바꾸면 다시 줄이고, 새 가로세로
    비율을 `style.css` 의 `.logo img { width: calc(var(--logo-h) * …) }` 에도
    옮겨 적어야 한다(비율이 바뀌면 로고가 눌리거나 늘어난다).
  - `wordmark/` — **홈 첫 화면에 실제로 걸리는 파일들.**
    `logo-fullname.png` 한 장을 넉 장으로 가른 것이다(각각 `.webp` + `.png`).
    지금 실제로 살아 있는 애니메이션이 별 반짝임과 글자 위 빛 지나가기뿐이라
    (끈 흔들림·구슬 미끄러짐은 2026-08-12/13 에 이미 껐다), 2026-09-11 로고
    교체 때 열 장에서 넉 장으로 정리했다.

    | 조각 | 내용 | 움직임 |
    |---|---|---|
    | `letters` | 별 3개를 뺀 나머지 전부(고리·끈·구슬·사각형·글자·리본) | 빛 지나가기 (히어로 높이의 기준) |
    | `star1`~`star3` | 몸통과 완전히 떨어진 별 셋 (원본엔 별이 넷인데, 끈에 닿아 있는 하나는 `letters` 에 남는다) | 반짝임 (크기·기울기·투명도) + 번쩍임 (밝기·후광) |

    겹치는 픽셀이 하나도 없다. 그래서 넉 장을 겹치면 원본과 **픽셀 단위로 같은**
    그림이 되고, 모션 줄이기 설정에서 애니메이션이 꺼져도 원본 그대로 보인다.
    합계 WebP 308KB.

  - `wordmark/w800/` — 위 넉 겹을 **화폭 800px 기준으로 줄인 WebP 넉 장**
    (합계 75KB). 좁은 화면 전용이다.
    800 은 눈대중이 아니다 — 가장 넓은 휴대폰(430px)에서 로고가 398px 로 보이고
    배율 2배 화면이면 796px 이 필요하다. 딱 그만큼이라 **배율 2배 휴대폰은
    전 기종이 이 한 벌로 덮인다.** 원본 겹은 2085px 이라 두 배 넘게 낭비였다.
    고르는 건 `index.html` 의 `srcset`/`sizes` 이고, 조건이 어느 겹이든
    **800 ≥ 로고폭 × 화면배율** 로 같아 넉 장이 대개 같은 크기끼리 짝을 이룬다.
    배율 3배 휴대폰과 데스크톱은 원본 308KB 를 받는다 — 배율 3배면 1194px 이
    필요해서 이 벌로는 모자라고, 그 화면들은 실제로 그 해상도가 필요하다.
    PNG 짝은 만들지 않았다. PNG 는 WebP 를 못 읽는 옛 브라우저용 폴백이라
    지금 쓰는 휴대폰과는 거의 겹치지 않는다.
    ⚠️ 줄일 때 알파를 곱해 두고 줄인 뒤 다시 나눈다(아래 `logo-fullname` 항목의
      같은 경고 참고). `build-wordmark.py` 의 `shrink_premultiplied()` 가 그렇게 한다.

    ⚠️ **손으로 고치지 말 것.** `python3 tools/build-wordmark.py` 가 만든다.
    로고를 새로 렌더링하면 그 스크립트를 다시 돌리고, 끝에 찍히는 좌표·색
    값을 `index.html` 의 인라인 style/alt·width·height 와 `style.css` 의
    `.wm-star-*` 에 옮겨 적어야 한다(그림에 딸린 값이라 자동으로 안 따라간다).
    가르는 원리와 주의점은 그 스크립트 맨 위 설명에 적어 두었다.
    (2026-08 판, NOMAD Lab 시절엔 끈·구슬 흔들림까지 열 장으로 갈랐다 —
    `split-wordmark.py`. 그 흔들림을 뺀 뒤로는 죽은 무게였고, 2026-09-11
    로고 교체 때 걷어냈다. 옛 구조가 필요하면 git 이력에서 찾을 것.)

  - `wordmark/letters-mask.png` — 글자 실루엣만 담은 **마스크** (500×175, 7KB).
    글자 위를 지나가는 빛(`style.css` 의 `wmShine`)을 글자 안에 가두는 데 쓴다.
    빛이 종이로 새지 않게 하려면 글자 모양대로 오려 낼 그림이 필요한데,
    `letters.png`(978KB)를 한 벌 더 받게 할 이유가 없어 따로 떴다.
    색은 안 쓰고 알파만 쓰므로 흑백(LA) PNG 다. WebP 짝을 만들지 않은 건
    CSS `mask-image` 에는 폴백 문법이 없어서다 — 못 읽는 브라우저가 하나라도
    있으면 마스크가 통째로 빠지고 흰 띠가 로고 사각형 위를 지나간다.
    `build-wordmark.py` 가 같이 만든다(직접 만드는 법도 그 스크립트 안에 있다).
    500px 로 줄이고 알파를 8단계로 뭉갠 건 파일을 가볍게 하려는 것이다.
    마스크는 부드러운 빛을 오려 내는 용도라 경계가 조금 무뎌도 화면에서
    차이가 보이지 않는다. 알파 24 미만을 버리는 건 글자 둘레의 옅은 후광까지
    빛이 번지지 않게 하려는 것.

  - `logo-fullname.webp` / `logo-fullname.png` — 위 넉 겹의 **원본 한 장**.
    연구실 로고의 전체 구성("LIFE:ON LAB", 2085×729, 2.861:1)이 풍선 글자로
    그려진 그림. 지금은 페이지가 직접 불러 쓰지 않는다(`wordmark/` 가 대신
    한다). 그래도 지운 적이 없다 — `build-wordmark.py` 의 입력이고 og-image
    후보의 바탕이다. 원본에서 알파가 있는 범위만 잘라낸 것이고 늘리지
    않았다. 본문 폭 1016px 에 걸어 쓰므로 2.05배 — 레티나 2배 요구를 넘는다.
    ⚠️ **배경이 투명하므로 JPEG 로 바꾸지 말 것** — JPEG 는 알파를 담지 못해
    투명한 자리가 검정으로 구워지고, 종이 위에 검은 띠가 뜬다(한 번 겪었다).
    같은 이유로 틀·대지·그림자를 두르지 않는다. 투명한 자리에 사각형이 드러난다.
    ⚠️ 줄일 때는 **알파를 곱해 두고(premultiply) 줄인 뒤 다시 나눈다.**
    그냥 줄이면 투명한 곳의 검정(0,0,0)이 번져 글자 가장자리에 검은 테가 생긴다.
    ⚠️ 낱글자 단위 애니메이션은 이 파일로 할 수 없다 — 풍선 글자가 서로 붙어
    있다. 글자별로 튕기게 하려면 글자마다 배경이 투명한 파일이 따로 있어야 한다.
  - `logo-mark.png` — 심볼만 (파비콘·프로필 사진용)
  - `logo-light.png` — 어두운 면(푸터·모달) 위에 얹는 밝은 버전
  - 같은 로고의 옛 버전을 남겨 둘 때만 뒤에 `_YYMMDD` 를 붙인다.
- 배경이 투명한 PNG(또는 SVG)로 올린다. 흰 사각형이 배경으로 박혀 있으면
  어두운 면 위에 얹을 수 없어 쓸 곳이 절반으로 줄어든다.
- 가로 폭은 최소 1200px 권장. 줄이는 건 되지만 늘리면 뭉개진다.

  손으로 파일명 번호를 올려 갈아 끼운다(자세한 이유와 절차는
  `tools/make-og-image.py` 맨 위 설명 참고 — 카카오톡 등은 주소 단위로
  미리보기를 캐시해 그림만 덮어쓰면 안 바뀐다).
